## Introduction
This guide covers tools that every student should know about.  
Technology has made studying easier, faster, and more organized.  
Students can now write code, manage notes, design presentations, and complete assignments using simple digital tools.  
In this guide, we discuss three important tools that can help students improve their academic work and creativity.  
Each section is written by a different team member.

## VS Code
**Written by Sean Awili**

Visual Studio Code, commonly called VS Code, is one of the best free code editors for students learning programming and web development.  
It supports many programming languages such as HTML, CSS, JavaScript, Python, and C++.  
Students can install useful extensions like Live Server, Prettier, and GitHub tools to make coding easier.

### Why students should use VS Code:
- It is free to download.
- It has a simple and clean interface.
- It helps detect coding errors quickly.
- It supports extensions for many tasks.
- It is useful for beginners and professionals.

VS Code is especially recommended for ICT and software development students because it improves coding speed and project organization.

## Notion
**Written by Brian Ouma**

Notion is an all-in-one productivity and note-taking application.  
Students can use Notion to create notes, daily schedules, to-do lists, assignment trackers, and project plans.  
Instead of keeping notebooks everywhere, a student can store all important information in one place.

### Benefits of Notion:
- Easy note organization.
- Allows adding images, links, and checklists.
- Can be shared with classmates.
- Helps manage deadlines.
- Good for personal study planning.

Notion is useful for students who want to stay organized and avoid forgetting tasks.

## Canva
**Written by Faith Achieng**

Canva is a simple online graphic design tool used for creating posters, presentations, CVs, certificates, social media posts, and school projects.  
Students who are not professional designers can still make attractive work using Canva templates.

### Why Canva is useful:
- Thousands of ready-made templates.
- Drag and drop editing.
- Free version available.
- Good for presentations and assignment covers.
- Easy to use on phone or computer.

Canva helps students make their academic work look more professional and creative.
